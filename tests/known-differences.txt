# Tests whose frames are known to differ from the QuarkTex 0.53 release.
# compare.py reports them as KNOWN instead of FAIL. One test per line:
# <test name> <reason>

t06_fog The 0.53 release draws fogged geometry black; the current build applies the fog colour and density as specified, and since phase 5 also without the z-buffer (first row).
a05_agl_queries The 0.53 release returns a host pointer from glGetPointerv (Amiga address plus the memory offset); the current build returns the Amiga address, which the yellow bar shows.
t10_zupdate Fixed in phase 5: W3D_ZBUFFERUPDATE switches depth writes. 0.53 never turned them off and switched blending instead (missing break), so the red quad hides the blue one and the green one is blended.
t11_texcolors Fixed in phase 5: W3D_SetTexEnv and W3D_SetWrapMode pass their colours as r, g, b, a; 0.53 passed r, b, g, a, so the green colours came out blue.
t12_texupdate Fixed in phase 5: W3D_UpdateTexSubImage uploads its image with srcbpr bytes per row. 0.53 uploaded the texture's original image instead and ignored calls with srcbpr != 0, so the blue and green rectangles are missing.
