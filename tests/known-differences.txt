# Tests whose frames are known to differ from the QuarkTex 0.53 release.
# compare.py reports them as KNOWN instead of FAIL. One test per line:
# <test name> <reason>

t06_fog The 0.53 release draws fogged geometry black; the current build applies the fog colour and density as specified, and since phase 5 also without the z-buffer (first row).
a05_agl_queries The 0.53 release returns a host pointer from glGetPointerv (Amiga address plus the memory offset); the current build returns the Amiga address, which the yellow bar shows. Since phase 5 the vertex array strip with stride 0 is drawn too.
t10_zupdate Fixed in phase 5: W3D_ZBUFFERUPDATE switches depth writes. 0.53 never turned them off and switched blending instead (missing break), so the red quad hides the blue one and the green one is blended.
t11_texcolors Fixed in phase 5: W3D_SetTexEnv and W3D_SetWrapMode pass their colours as r, g, b, a; 0.53 passed r, b, g, a, so the green colours came out blue.
t12_texupdate Fixed in phase 5: W3D_UpdateTexSubImage uploads its image with srcbpr bytes per row. 0.53 uploaded the texture's original image instead and ignored calls with srcbpr != 0, so the blue and green rectangles are missing.
t03_textures Fixed in phase 5: CHUNKY textures go through their palette (first quad). 0.53 sent the indices as GL_COLOR_INDEX and ignored the palette.
t13_texswap Fixed in phase 5: texture updates set the byte order of their format. 0.53 kept the one of the last allocation, so after an 8-bit allocation the R5G6B5 updates came out with swapped bytes (green/blue and red/white).
t14_zbuffer_io Fixed in phase 5: W3D_ReadZPixel/ReadZSpan and W3D_WriteZPixel/WriteZSpan read and write Warp3D depth values at the right place. 0.53 returned garbage (no bars) and wrote no rows.
a06_agl_pixels Fixed in phase 5: 16-bit and float pixel data (glDrawPixels, glTexSubImage2D, glReadPixels) and the glCallLists names arrive in the right byte order. 0.53 scrambled the image (top left), left out the green sub-image, drew two of the three squares, and read back garbage (missing bars).
