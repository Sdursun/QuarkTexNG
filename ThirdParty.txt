2. GCC runtime libraries (in the host DLLs)
-------------------------------------------

The host DLLs link libgcc and libstdc++ statically. They are under the GNU
GPL v3 with the GCC Runtime Library Exception, which lets programs compiled
with GCC include them under terms of the program's own choosing; QuarkTex
NG's are the GNU LGPL v3.


3. Warp3D API include files (not in the Aminet archive)
-------------------------------------------------------

Warp3D.library/Warp3D.h and Warp3D.library/Warp3D.fd are the include files
of the Warp3D API, (C) 1998 Sam Jordan, Hans-Joerg Frieden, Thomas Frieden,
all rights reserved; they came with QuarkTex and are used, unchanged, so
that QuarkTex NG's Warp3D.library offers the same interface. They are not
under the LGPL and are left out of the source in the Aminet archive;
Source/Warp3D.library/Warp3D-includes.txt there says where to get them.

5. MiniGL SDK (not included)
----------------------------

minigl.library is QuarkTex NG's own implementation of MiniGL's shared
library interface. Building it reads the include files of MiniGL's SDK,
(C) 1999-2002 Hyperion, under the Hyperion MiniGL Open Source License,
which allows MiniGL to be compiled for code running on AmigaOS and asks
that the source of modifications be made public to the Amiga developer
community; QuarkTex NG's source is in Source/. The SDK is not part of this
release (see docs/phase7-minigl.md in Source/ for building).


6. Picasso96 and AmigaOS include files (not included)
-----------------------------------------------------

The Amiga libraries are built with the AmigaOS and Picasso96 include files
of the m68k-amigaos-gcc toolchain; none of them is part of this release.
